# 中文技术报告规范

## 结构

1. **结论速览**：三五条要点，先给答案。读者只看这一段也能拿到 80% 的价值。
2. **方法与证据**：怎么得到的结论（读了哪些文件、跑了什么命令、查了哪个页面），带可复现的路径或链接。
3. **正文**：按主题分节，每节一个判断，不要按"收集顺序"堆材料。
4. **待确认 / 未知**：明确列出没验证的部分，不要让读者误以为全都核实过。

## 写作

- 断言要能对应到证据。区分"我实测到"和"我推断"，用不同措辞。
- 对比类信息一律上表格：列少、行少、每格尽量短。
- 数字带单位和口径（例如"1.9T，98% 满"而不是"快满了"）。
- 中英混排时，英文术语首次出现给中文解释。

## 禁忌

- 不用 emoji，不用感叹号堆情绪。
- 不写"众所周知""显而易见"这类填充语。
- 不要为了显得充实而重复同一结论。
- 引用外部内容时给出原始 URL，不要给二手转载。
